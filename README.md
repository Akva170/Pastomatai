# Siuntų pristatymo paštomatais sistema

Tai akademinis programų sistemų analizės ir projektavimo projektas, kuriame modeliuojama siuntų pristatymo paštomatais sistema. Sistema skirta siuntų registravimui, apmokėjimui, sekimui, paštomatų valdymui ir kurjerio maršrutų planavimui.

Projekto tikslas – suprojektuoti ir iš dalies realizuoti siuntų pristatymo paštomatais sistemą(pagrindinį funkcionalumą), pritaikant programų sistemų analizės ir projektavimo principus. Projekte daug dėmesio skiriama UML diagramoms, reikalavimų specifikavimui, sistemos architektūrai ir realizacijos atitikimui projektavimo modeliui.

## Projekto funkcionalumas

- Vartotojo registracija ir prisijungimas
- Siuntos registravimas
- Siuntos apmokėjimas per išorinę banko / mokėjimo sistemą
- Siuntos sekimas pagal siuntos kodą
- Siuntos įdėjimas į paštomatą
- Siuntos išėmimas iš paštomato
- Vartotojų sąrašo peržiūra ir filtravimas
- Vartotojų rolių keitimas
- Vartotojo paskyros šalinimas
- Paštomatų sąrašo peržiūra ir filtravimas
- Paštomatų kūrimas ir šalinimas
- Paštomatų žemėlapio peržiūra
- Kurjerio maršruto optimizavimas pagal paštomatų prioritetus

## Sistemos rolės

- **Svečias** – gali registruotis ir sekti siuntą pagal kodą.
- **Klientas** – gali prisijungti, registruoti siuntas, peržiūrėti savo siuntas ir naudotis siuntų funkcijomis.
- **Administratorius** – gali valdyti vartotojus, roles ir paštomatus.
- **Kurjeris** – gali peržiūrėti optimizuotą paštomatų aptarnavimo maršrutą.

## Naudotos technologijos

- **React** – naudotojo sąsajai kurti
- **Node.js** – serverio logikai ir API užklausoms apdoroti
- **phpMyAdmin / SQL duomenų bazė** – duomenų saugojimui
